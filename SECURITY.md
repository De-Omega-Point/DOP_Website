# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities publicly.

Send a concise report to `contact@de-omega-point.com` with:

- the affected feature or file
- reproduction steps
- expected and observed behaviour
- potential impact
- any suggested remediation

De-Omega-Point will acknowledge credible reports and prioritise fixes according to severity and user impact.

## Client-side AI note

The optional Transformers.js model runs in the visitor's browser. Do not place secrets, private API keys, credentials, or confidential business data in client-side code or prompts.
